# Future Integration: linguistic-polyformalism-shell

## Current State
An MCP server that produces novel insights by solving problems through the grammatical constraints of 14 human languages across 7 language families. Discovered 7 fundamentally different meanings of "constraint" — no single language captures all. The intersection of all 7 approaches completeness.

## Integration Opportunities

### With construct-core skill auditing
The 7 constraint types (Boundary, Pattern, Process Shape, Knowledge Source, Social Structure, Deep Structure, Instrument) become the taxonomy for construct-core's SkillSpec capabilities. A skill declared with all 7 types has complete self-description. A skill missing types has blind spots. The polyformalism shell becomes the skill auditing tool.

### With ternary-registry capability discovery
When ternary-registry catalogs skills, it uses the 7-type taxonomy. Searching for skills becomes: "I need a skill with Boundary constraint (defines what it IS) and Process Shape (shapes event flow)." The taxonomy enables precise skill discovery.

### With room description
When the NLP-Explainer describes a room, it uses the 7-type framework: the room's Boundary (what it IS), Pattern (how it guides), Process Shape (how events flow), Knowledge Source (where its knowledge comes from), Social Structure (power dynamics), Deep Structure (root patterns), and Instruments (tools available). Complete room description.
