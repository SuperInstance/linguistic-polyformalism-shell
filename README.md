# Linguistic Polyformalism Shell

**An MCP server that produces novel insights by solving problems through the grammatical constraints of 14 human languages across 7 language families.**

Programming languages constrain computation. Human languages constrain cognition. When you think in Ancient Greek, you think in categories, definitions, and telos. When you think in Classical Chinese, you think in relationships, patterns, and processes. When you think in Navajo, you think in shapes, motions, and events.

This shell operationalizes a Sapir-Whorf approach to creative cognition: instead of translating a problem between languages, you *think* in each language's grammatical toolkit and harvest the insights that only emerge under different cognitive constraints.

---

## The 7-Type Constraint Discovery

| Type | What It Does | Neural Basis |
|------|-------------|-------------|
| Translation | Map problem into another language's ontology | DMN → semantic network |
| Constraint injection | Force grammatical rules onto problem structure | ECN → rule enforcement |
| Vacillation | Alternate between languages until convergence | DMN ↔ ECN switching |
| Analogy | Find isomorphic structures across languages | Semantic network |
| Inversion | Solve the dual language problem | ECN → counterfactual |
| Hybridization | Combine constraints from multiple languages | DMN → ECN binding |
| Obliviscence | Forget the constraints that aren't helping | DMN → attention filtering |

## Supported Languages

| Family | Languages |
|--------|-----------|
| Indo-European | Ancient Greek, Latin, Sanskrit, English |
| Sino-Tibetan | Classical Chinese, Mandarin |
| Na-Dené | Navajo |
| Afro-Asiatic | Classical Arabic, Hebrew |
| Austronesian | Hawaiian, Māori |
| Uralic | Finnish |
| Constructed | Lojban, Ithkuil |

Each language family imposes different ontological commitments — what kinds of entities exist, what relationships are grammatically available, what modes of reasoning the syntax allows.
