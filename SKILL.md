# Linguistic Polyformalism Shell 🐚🌍

## What This Shell Does

Transforms any agent into a **cross-linguistic thinker** that produces novel insights by approaching problems through the grammatical constraints of different human languages.

**Based on the discovery that "constraint" means fundamentally different things in different linguistic traditions.** No single language captures all dimensions of thought.

## Quick Start

```
1. Read this SKILL.md
2. Pick a problem to solve
3. Choose 2-3 linguistic modes from the MODE TABLE
4. Solve the problem in each mode (NOT translating — THINKING differently)
5. Cross-reference insights using the SYNTHESIS protocol
```

## The Core Principle

**Programming languages constrain computation. Human languages constrain cognition.**

When you think in Ancient Greek, you think in categories, definitions, and teleology (telos). When you think in Classical Chinese, you think in relationships, patterns, and processes. When you think in Navajo, you think in shapes, motions, and events.

These produce **genuinely different solutions** to the same problem.

## Linguistic Mode Table

### Indo-European Family: Thing-Oriented Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Ancient Greek** | Aspects (aorist/perfect/present), middle voice, participles, definite article | Categories, definitions, telos, self-referential processes |
| **Russian** | Aspectual pairs, 6 cases, prefix-stacking | Process phases, relationships, directional modifications |
| **German** | Verb-final subordinates, separable verbs, 3 genders | Planned execution, distributed meaning, gendered categorization |

### Sinitic Family: Relationship-Oriented Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Classical Chinese** | Topic-prominent, no tense/plural/case, multigrade words, no copula | Relationships, patterns (理), processes, holistic coherence |

### Native American Family: Process-Oriented Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Navajo** | Classificatory verb stems (shape+motion), verb-centric, polysynthetic | Event shapes, object classification by form, process-as-primary |
| **Nahuatl** | Noun incorporation, absolute/possessed distinction, reverential | Objects-as-processes, inherent vs external properties, respect |
| **Quechua** | Evidentiality (-mi/-si/-chá), inclusive/exclusive "we" | Knowledge source, epistemic status, collective vs individual |

### Agglutinative Family: Layered-Meaning Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Korean** | 7 honorific levels, topic/subject/object markers, agglutination | Social context, layered meaning, attention structure |
| **Japanese** | wa/ga distinction, concessives, aspect+mood combinations | Topic vs subject attention, contradiction tolerance, temporal nuance |
| **Finnish** | 15 cases (including abessive "without", instructive "by means of"), no gender | Instruments, means, absences, relational freedom |

### Semitic Family: Deep-Structure Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Arabic** | Root-and-pattern morphology, consonantal roots | Deep structure vs surface form, pattern extraction |
| **Amharic** | Root-and-pattern, jussive/gerund | Intentionality, deep patterns, command forms |

### African Family: Multi-Class Thinking

| Language | Key Grammar Features | What It Forces You To Think About |
|----------|---------------------|----------------------------------|
| **Swahili** | 18 noun classes, agreement propagation | Categorical shape, animacy, artifact classification |
| **Yoruba** | Tonal, isolating, Ifá divination binary/ternary | Pitch-meaning, combinatorial patterns, binary logic |

## The 7-Type Constraint Discovery

When we analyzed "constraint" across languages, we found 7 fundamentally different concepts:

1. **Boundary** (Greek πέρας): Constraint = definition = identity
2. **Pattern** (Chinese 法): Constraint = guidance, not limitation
3. **Process Shape** (Navajo): Constraint = shape of events
4. **Knowledge Source** (Quechua -mi/-si/-chá): Constraint = evidence tracking
5. **Social Structure** (Korean): Constraint = power dynamics
6. **Deep Structure** (Arabic ق-ي-د): Constraint = root vs surface
7. **Instrument** (Finnish abessive): Constraint = optional tool

**No single language captures all 7.** The intersection approaches completeness.

## How To Think In A Language Mode

**WRONG**: "How would I translate this sentence into Chinese?"
**RIGHT**: "If my grammar had no subject-verb distinction, no tense, and every word could be noun/verb/adjective simultaneously, how would I conceptualize this problem?"

The grammar FORCES the thinking:
- Greek middle voice → "the system monitors itself" (not "we monitor the system")
- Chinese topic-prominence → "the system, its behavior changes" (not "the system changes behavior")
- Navajo classificatory verbs → "the round-flowing-object moves constrainedly" (not "water flows through a pipe")
- Quechua evidentiality → "the constraint holds [I directly observe]-mi" vs "the constraint holds [I infer]-chá"

## The Experiment Protocol

### Step 1: State the Problem (in English)
One clear sentence.

### Step 2: Solve in Language A
Using ONLY the grammatical thinking tools of Language A. Document:
- What concepts are natural in this language?
- What concepts are impossible to express?
- What architectural form does the solution take?

### Step 3: Solve in Language B
Same problem, different grammatical toolkit. Document the same.

### Step 4: Solve in Language C
Third perspective.

### Step 5: Cross-Reference
- Which insights appear in ONLY one language? (These are the gems.)
- Which insights appear in all three? (These are the universal truths.)
- What new concept emerges from the intersection that NO single language contains?

## Complete Cognitive Set

The minimum set of languages that covers all thought dimensions:
1. **Ancient Greek** — Entity-action categorization (ontological thinking)
2. **Classical Chinese** — Topic-relation holistic thinking (relational thinking)
3. **Navajo** — Process-animacy event thinking (event-based thinking)
4. **Arabic** — Root-pattern deep structure (transform thinking)
5. **Finnish** — Case-modular instrumental thinking (relational-freedom thinking)

Remove any one and you lose a cognitive dimension.

## Top 5 Orthogonal Pairs (Maximum Insight Production)

1. **Navajo ↔ Ancient Greek** — Process-centric ↔ Thing-centric (MAXIMUM gradient)
2. **Classical Chinese ↔ Russian** — Relational ↔ Directional/aspectual
3. **Quechua ↔ Korean** — Epistemic tracking ↔ Social tracking
4. **Yoruba ↔ Finnish** — Tonal/isolating ↔ Case-rich/agglutinative
5. **Nahuatl ↔ Prolog** — Noun-incorporation ↔ Declarative logic
